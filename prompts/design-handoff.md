# Design handoff

Use this when the Lead has a clear user outcome and a new or unsettled interaction. Give the [UX Design Companion](https://github.com/willbergin/ux-design-companion-agent) the issue, target user, existing patterns, and constraints.

> Propose the primary journey and relevant alternate paths. Describe each applicable empty, loading, error, and success state. Include accessibility and responsive requirements where relevant. List decisions that need input and write observable acceptance criteria. Return a brief the Lead can add to the issue for the Builder and Reviewer.
