# Record a project decision

> Draft a short decision record for the app repo. Include the date and status, the issue or PR, the context and constraints, the decision, the alternatives considered, why the selected option fits, the trade-offs, and a concrete condition for revisiting it. Use the app’s existing decision record location and format where available.

Use this for decisions that affect future changes, such as where permissions are enforced, how a migration is sequenced, or which evaluation threshold gates a model change.
