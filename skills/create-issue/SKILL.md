---
name: create-issue
description: Quickly capture a bug or feature in Linear while working on another task.
---

1. Capture the title, observation or user outcome, and relevant context. For a bug, include expected and actual behaviour and any known reproduction steps. Leave missing details open.
2. Search the configured Linear team or project for a match. Reuse a matching issue and add new evidence only when authorised.
3. Create the issue when authorised. After a timeout, look it up before retrying. If access or authorisation is missing, return a draft using the [issue template](../../prompts/linear-issue.md).
4. Return the issue link or draft and resume the original task. Use shape-issue separately when the work needs planning.
