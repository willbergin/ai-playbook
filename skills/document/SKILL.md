---
name: document
description: Update project documentation to reflect a code change and its effects on users or maintainers.
---

1. Read the issue, diff, and existing documentation. Identify changed behaviour, setup commands, configuration, interfaces, or migration steps.
2. Update the existing source of truth with the smallest accurate edits. Add a page only when existing docs have no suitable home.
3. Verify examples, links, and commands against the implementation and note checks you could not run.
4. Record the docs changed or why the change has no documentation impact. Include updates in the candidate before final review.
