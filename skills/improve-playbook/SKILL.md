---
name: improve-playbook
description: Use recurring delivery failures to refine a shared skill or project instruction.
---

1. Gather the observed failures and identify the instruction, missing context, or handoff detail that contributed.
2. Put reusable guidance in the relevant shared skill. Put app-specific conventions in that app's instructions. Inspect existing guidance for overlap.
3. Propose a small change and a concrete example that demonstrates how it would prevent the recurrence. Check affected links and setup instructions.
4. Show the proposed diff or apply it when requested. State how to verify the improvement on a future run.
