description: Pause the current task to explain unfamiliar code, a design decision, or an error.

1. Identify the question and the current point in the task. Read the relevant snippet, decision, or output.
2. Explain the concept in the user's terms, then show how it applies here. Give a small example or a quick check for understanding when useful. Flag any assumptions.
3. Keep this pass read-only. End with a short recap and the next action so the user can resume when ready.
